# IT3130 Git Basics Lab

## Purpose
This repository demonstrates a basic Git workflow for IT3130.

## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation

## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned

Through this practical, I learned how Git separates the working directory, staging area, and local repository. I understood that `git add` moves changes to the staging area, and `git commit` saves them permanently to the local repository. I also learned how to connect a local repository to a remote GitHub repository using `git remote add` and push changes with `git push`. The `-u` flag in the first push sets the upstream branch, so future pushes only need `git push`.
